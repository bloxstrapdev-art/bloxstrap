# bloxstrap



[![bloxstrap](https://bloxxstrap.com/assets/bloxstrap-logo-124-v2.webp)](https://bloxxstrap.com/)



Welcome to the official companion repository for [bloxstrap](https://bloxxstrap.com/) — a free, open-source Roblox launcher and bootstrapper for Windows that gives you far more control over how Roblox starts, looks, and behaves on your PC. If you have ever wished Roblox felt a little more like *yours*, this project is exactly that.



## What is bloxstrap?



[bloxstrap](https://bloxxstrap.com/) is a lightweight, community-built replacement for the default Roblox launcher. Instead of a plain black window and a loading bar, you get a polished, customizable front end with a long list of quality-of-life features. It works alongside the standard Roblox client — you still play the same games, join the same servers, and use the same account, but everything around the launch experience is improved.



The project is completely free and open source. There are no ads, no premium tiers, and no shady modifications to your game. Development is driven by players who simply wanted a better launcher.



![bloxstrap settings panel](https://bloxxstrap.com/assets/bloxstrap-settings-panel-711-v2.webp)



## Key features



### Custom cursors and sounds

Replace the standard Roblox mouse cursor with your own design, and swap the in-game sounds for custom audio packs. Whether you want a cleaner cursor for precise aiming or funny sound effects for a stream, it all lives inside the launcher settings.



### Discord Rich Presence

Show off what you are playing directly on your Discord profile. Bloxstrap can display the game name, server, and other details so friends know exactly where to find you in Roblox.



### Server region and details

See which region a server is hosted in before you join, helping you pick lower-latency matches and avoid laggy experiences.



### Fast Flags (FFlags)

Fast Flags are Roblox's internal configuration toggles. Bloxstrap makes applying them easy and safe, letting you tweak rendering quality, FPS caps, and other advanced options — with presets so you don't have to memorize values.



### Mods and integrations

Beyond cosmetics, bloxstrap supports community mods, custom launch options, and integrations that make the whole Roblox ecosystem feel more flexible.

## Frequently asked questions



**Is bloxstrap allowed by Roblox?**

Bloxstrap is a launcher replacement, not a game exploit. It does not give unfair advantages; it mainly changes how Roblox launches and looks.



**Does it affect performance?**

Many users report smoother performance because the launcher gives access to graphics and FPS options that the default Roblox client hides.



**Is it free?**

Yes. The launcher is free and open source.



**Does it still let me play normal games?**

Absolutely. You log in with your normal Roblox account and play the same experiences.
